
# Dataset Information

## Dataset Source

AquaWatch uses the Slovak water infrastructure SCADA dataset.

- **Source:** Zenodo
- **DOI:** https://doi.org/10.5281/zenodo.15096167
- **Format:** CSV
- **Observations:** 8,737
- **Frequency:** Hourly

## Download Instructions

1. Visit the original Zenodo dataset.
2. Download the CSV file.
3. Place it in the project directory as required by the notebook.

## Important Note

The original dataset is not included in this repository. Please refer to the original source for its licence, usage conditions, and attribution requirements.
